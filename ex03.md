# Übung 5: Strukturen

## Aufg. 1
  Erstelle eine Klasse "Strukturen" inkl. Main-Methode.

## Aufg. 2
  Erstelle eine weitere Klasse "Kontakt" (ohne Main-Methode).

## Aufg. 3
  Überlege, wie man typische Kontaktinformationen abspeichern kann. Ergänze dafür geeignete Properties.

## Aufg. 4
  Füge einem "Adressbuch" Kontakte hinzu.

## Aufg. 5
  Sorge dafür, dass ein Kontakt bereits beim Anlegen immer mind. einen Vornamen, Nachnamen und eine E-Mail-Adresse zugewiesen bekommt.

## Aufg. 6
  Implementiere für die Klasse Kontakt das Attribut 'Emailadresse' so, dass es per Get von außen abgefragt werden kann und dass es beim Set generell eine Prüfung durchgeführt wird, ob sich ein '@' in der E-Mail-Adresse befindet.
