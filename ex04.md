# Übung 4: Klassen

## Aufg. 1
  Erstelle in einer neuen Datei eine Klasse **Test** inkl. Main-Methode.
  Erstelle in der selben Datei eine weitere Klasse **A** (ohne Main-Methode).
  Teste, in dem die Main-Methode in Klasse **Test** eine Variable **a** vom Typ **A**
  erstellt (initialisiert). Gib zum Testen per
  `Console.WriteLine(a)`
  **a** auf der Console aus.

## Aufg. 2
  Überschreibe die `ToString()`-Methode und gib einen selbst definierten Text aus.
  Teste erneut die Ausgabe von **a** auf der Console.

## Aufg. 3
  Überlege dir für die Klasse **A**
  - eine Klassenmethode, die unabhängig von der Existenz eines Objekts verfügbar ist.
  - eine Objektmentode, die spezielle Eigenschaften eines konkreten Objekts verarbeitet.

  Verwende beide Methoden beispielhaft und zeige die Unterschiede 
  - in der Anwendung (Wie rufe ich sie auf) 
  - und in der Eigenschaft (Was leisten sie)

## Aufg. 4
  Erstelle eine Klasse **B** als innere Klasse von **Test**.
  Erstelle eine Variable **b** vom Typ **B**
  - innerhalb der Klasse **Test**
  - innerhalb der Klasse **A**
  
  Was sind die Unterschiede?
