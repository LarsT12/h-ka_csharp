# Listen und Methoden

## Aufg. 1
  Erstelle eine Klasse "Messdaten", welche in der Main-Methode eine Liste von Temperaturmessdaten als Variable temperaturen mit ca. 10 Messwerten initialisiert.

## Aufg. 2
  Schreibe Funktionen zur Berechnung des Mittelwerts, Minimums, Maximums. Gib die Ergebnisse auf der Console aus.

## Aufg. 3
  Schreibe eine Funktion zur Berechnung des Medians. Gib das Ergebnis auf der Console aus.

## Aufg. 4
  Schreibe eine Funktion zur Berechnung der Anzahl an Werten innerhalb eines Bereichs, inkl. der Grenzenwerte [min, max]. Gib das Ergebnis auf der Console aus.
