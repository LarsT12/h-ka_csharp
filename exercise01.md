# Kontrollstrukturren

## Aufg. 1
  Schreibe eine Klasse namens "Sequenz", die
  mehrere Ausgaben enthält, die als Sequenz deine Morgenroutine (Aufstehen, Duschen ...) beschreibt.

## Aufg. 2
  Schreibe eine Klasse namens "Selection", die
  in Abhängigkeit einer Variable entscheidet, 
  welche Teilsequenz, ausgeführt werden soll.
  Dafür lässt sich die Sequenz aus Aufg. 1 verwenden.

## Aufg. 3
  Schreibe eine Klasse namens "Loop", die
  eine Sequenz von mind. 2 Anweisungen
  mehrmals wiederholt
