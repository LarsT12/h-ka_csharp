# Aufg. Räume

## Teil 1
Erstelle ein struct "Raum", um Räume an der H-KA abzubilden. Sie sollen
- eine Raumnummer (Alphanumerisch) haben
- eine Anzahl Plätze haben
- erkennbar als Laborräume (mit PC) geführt werden

- gebucht werden können, i.S.v. (frei/belegt)
- das Zugang/Abgang von Personen ermöglichen und sich die Anzahl der Personen merken, die im Raum sind. Sowohl Zu- als auch Abgänge sind positive Werte, was geprüft werden muss.

## Teil 2
Erstelle ein Array von 5 Räumen, initialisere/konstruiere und teste mind. zwei Räume das Buchen sowie den Zu- und Abgang

## Teil 3
Erstelle einen Konstruktur, so dass man direkt
- Raumnummer
- Anzahl Plätze
- Laborraum (oder nicht)
beim Erstellen mitgeben kann.
