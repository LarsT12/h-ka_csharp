# Variablendeklaration

## Aufg. 1
  Erstelle eine Klasse namens "Block" mit
  einer Ausgabe zur Begrüßung.
  
## Aufg. 2
  Deklariere die Variablen j vom Typ int innerhalb der Main-Methode und initialisiere j mit einem Wert.
  Deklariere eine weitere Variable k vom Typ int innerhalb eines Blocks {}, der sich innerhalb der Main-Methode befindet. Weise ihr den Wert von 2 * j zu.
  Gebe k innerhalb des Blocks auf der Console aus.
  
## Aufg. 3
  Versuche k außerhalb des Blocks auf der Console auszugeben und interpretiere die Fehlermeldung, 
  die beim Kompilieren erscheint.
  
## Aufg. 4
  Erkläre, wie sich die Sichtbarkeit von Variablen von innen nach außen verhält. 
  Erkläre ebenfalls die Sichtbarkeit von Variablen von außen nach innen - 
  betrachte dazu die in Aufg. 2 durchgeführte Berechnung.

## Aufg. 5
  Deklariere erneut die Variable j als static int außerhalb der Main-Methode, 
  aber noch innerhalb der Klasse, und weise ihr einen Wert zu.
  Analysiere, welche Variable j verwendet wird, die außerhalb der Main-Methode oder die innere?
  Setze für der inneren Variable j Kommentarzeichen, compilieren den Code neu und führe ihn aus.
  Was hat sich geändert?
